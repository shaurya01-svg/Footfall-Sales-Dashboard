# Footfall-Sales-Dashboard

An interactive Machine Learning and Explainable AI based retail analytics dashboard that analyzes the impact of customer footfall on Walmart weekly sales.

## Features
- Interactive Streamlit Dashboard
- Sales Prediction using Linear Regression
- SHAP Explainable AI
- Footfall vs Sales Analysis
- Correlation Heatmap
- Holiday vs Sales Comparison
- Temperature vs Sales Analysis
- Store-wise Insights
- Interactive Filters

## Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- SHAP
